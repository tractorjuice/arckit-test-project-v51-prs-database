# PRS Database

**Project ID**: 001
**Created**: 2026-05-28
**Owner**: MHCLG (Ministry for Housing, Communities and Local Government)

UK national Private Rented Sector (PRS) database — a mandatory register of landlords and rental properties under the Renters' Rights Act 2025 (UKPGA 2025/26, Part 2).

Phased rollout from late 2026:
- Stage 1: landlord and property registration (area-by-area)
- Stage 2: public tenant lookup view

See `/CLAUDE.md` for full domain context.
